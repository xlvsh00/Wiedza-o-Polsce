# Wiedza o Polsce

Aplikacja webowa typu gry **Wiedza o Polsce.**

Główne funkcje i zasady gry: Brak logowania: Gra jest w pełni dostępna od razu po wejściu na stronę.

	1. Cel gry: Zgadnij odpowiedź z historii Polski (np. 1 król Poalskii, Bitwa pod Grunwaldem).
	
	2. Gra losuje wydarzenie, a czytasz lub wybierasz go z 4 odpowiedzi. Runda to 25 pytań.
	
	3. Punktacja: Trafiona odpowiedź daje 1 pkt maksymalnie możesz zdobyć 25 punktów.
	
	4. Czas: Na każde pytanie masz nielimitowany czas.
	
	5. Podpowiedzi: Brak klasycznych podpowiedzi zamiast tego możesz skorzystać z innego sposobu.
	
	6. Poziomy trudności: Łatwy (najważniejsze daty).
	
	7. Wynik końcowy: Po ostatnim pytaniu zobaczysz sumę punktów, poprawne odpowiedzi i krótkie ciekawostki.
